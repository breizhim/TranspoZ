Transposer la sélection

Appliqué dès le clic (annulable avec Ctrl+Z).

Cliquez entre deux notes pour placer le début de la sélection, puis la fin (en orange). Seule la sélection est transposée : le reste de la partition n'est pas touché.

Cliquez sur une note (ou entre deux notes) pour ajouter, changer ou retirer une nuance (pp, mf, ff…) ou une indication (cresc., rit.…). Cliquez sur une barre de mesure pour un repère encadré (A, B, C…). Un soufflet se modifie depuis la note où il commence ou finit. Soufflet
Cliquez dans une mesure pour changer la clé, l'armure ou le chiffrage à partir de celle-ci, ou le nombre de mesures d'une pause (mesure de silence).
